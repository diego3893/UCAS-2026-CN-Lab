# P8本地测试与截图指南

## 1 目录与提交文件

`08-mospf.tar.gz`和`08-mospf/`保留课程原始附件。实现及测试位于`mospf/`，程序名为`mospfd`，不改名为router。OJ上传`mospf-submit.zip`，不要上传整个实验目录。ZIP只包含12个C文件、头文件和原始Makefile，不含Python、P3交换机、参考程序、日志或编译产物。

所有命令不含提示符。WSL命令和Mininet命令分开执行；Mininet中的多条命令建议逐条粘贴、等上一条结束，避免粘贴内容与进程输出交错。

## 2 运行环境与编译

Windows终端进入Ubuntu：

```powershell
wsl -d Ubuntu-24.04
```

WSL中进入代码目录（二选一）：

```bash
cd "/mnt/c/Users/30130/Desktop/CN_Lab/P8 网络路由/mospf"
```

若你的代码复制在Linux家目录，使用：

```bash
cd "$HOME/CN_Lab/P8 网络路由/mospf"
```

安装依赖并编译：

```bash
sudo apt-get update
sudo apt-get install -y build-essential mininet iproute2 arptables iptables ethtool tcpdump traceroute iputils-ping
make clean
make
```

截图1：保留编译命令和最后成功链接`mospfd`的输出。packed结构体相关警告是框架原有问题，不等于编译失败；不需要改Makefile屏蔽。

## 3 自动验收与证据

在WSL中依次运行，不要同时启动两个Mininet：

```bash
sudo python3 lab_test.py
sudo python3 lab_test.py --mode switch
```

第一条在同一个课件拓扑中等待40秒，检查双向ping、路由和数据库，按实际traceroute所经链路断链，继续等待40秒，再检查通信和备用路径。第二条建立共享二层网段，运行P3用户态交换机，等待30秒后检查。等待时间是验收观察点，不是精确测出的最短收敛时间。

交换机模式默认使用`../../P3 Hub Switch/03-hub+switch/switch/switch`，不是Linux内核网桥。若路径不同，用`--switch-binary`指定你已编译的P3可执行文件；若需要编译，请在对应P3目录用原始Makefile编译，勿将switch打包进OJ。

每次运行都会打印新建的`test-results/run-时间/`目录，保存`transcript.txt`、`results.json`、初始/断链后状态快照、各路由器stdout/stderr和真实`mospf.pcap`。可只读检查该次证据：

```bash
python3 check_evidence.py ../test-results/simple-verified
python3 check_evidence.py ../test-results/switch-verified
```

上面两个目录是交付时保留的实测记录；核对自己新跑的结果时，换成新目录。文件中的`RID`是本机ID，`NBR`是接口邻居，`LSA`是远端源路由器、序号、网络、掩码、邻居RID，`ROUTE`是目的网络、掩码、网关、接口。原始`.state`中的IP用主机序整数保存，脚本生成的`.txt`已转换为点分十进制。

## 4 手动获取报告截图2—5

在WSL中启动课件拓扑并自动运行全部mospfd：

```bash
sudo python3 lab_test.py --interactive
```

进入Mininet后，不要再手动运行第二份mospfd。先等待40秒：

```text
sh sleep 40
h1 ping -n -c 2 -W 2 -w 6 10.0.6.22
h2 ping -n -c 2 -W 2 -w 6 10.0.1.11
h1 traceroute -I -n -q 1 -w 2 -m 8 10.0.6.22
```

截图2：双向ping的2/2、0%丢包、TTL及完整路径。典型初始路径为10.0.1.1→10.0.2.2→10.0.4.4→10.0.6.22；等价路径也可能经r3，应以实际输出为准。

在另一个WSL终端进入同一`mospf/`目录，根据脚本启动时打印的目录读取状态：

```bash
python3 -c 'from pathlib import Path; from lab_test import readable; print(readable(Path("../test-results/你的本次目录/r1.state")))'
```

将路径中的“你的本次目录”替换为真实目录名，再把r1换为r2、r3、r4检查其他节点。截图3：四台路由器的LSA快照（可拆图），说明同一发布者的通告内容一致；各节点不保存自己的LSU条目，所以数据库的行数并不一定相同。不能仅凭“每台都有3个远端RID”就认定内容一致。

回到原来的Mininet，根据实际使用路径选择断链。如果第二跳为10.0.2.2：

```text
link r1 r2 down
sh sleep 40
h1 ping -n -c 2 -W 2 -w 6 10.0.6.22
h2 ping -n -c 2 -W 2 -w 6 10.0.1.11
h1 traceroute -I -n -q 1 -w 2 -m 8 10.0.6.22
```

若第二跳为10.0.3.3，第一条改为`link r1 r3 down`。截图4：断链命令、40秒等待命令、正常ping与改变后的完整路径。不要退出后重新建立拓扑替代这项测试。两次traceroute至少间隔5秒，上述40秒等待已满足。

截图5：再读取r1的状态，与断链前比较`10.0.6.0/24`的下一跳；断r1—r2时应由10.0.2.2/r1-eth1变为10.0.3.3/r1-eth2。同一命名空间内的Linux`ip route`只包含启动配置，不包含用户态程序计算的动态路由，不能拿它当动态路由表截图。

```text
exit
```

## 6 截图7：真实Hello和LSU

Windows Wireshark打开本次输出目录中的`mospf.pcap`。课程Lua解析器在`mospf/wireshark/mospf.lua`，按Wireshark菜单Help→About→Folders中“Personal Lua Plugins”路径放置，重启Wireshark。该目录不存在时可以创建，Windows普通用户与WSL root的插件目录不同。

过滤条件：

```text
ip.proto == 90
```

截图7(a)：Hello外层目的IP为224.0.0.5，目的MAC为01:00:5e:00:00:05，版本2，Hello间隔5秒。截图7(b)：LSU的原发布者RID、序号、TTL、nadv及通告列表。交换机模式可选一份在同一10.0.2.0/24网络包含多个邻居RID的LSU。
