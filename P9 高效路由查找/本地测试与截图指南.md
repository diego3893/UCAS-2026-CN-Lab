## 3 图2—4：独立正确性、五轮性能、内存

从当前`ip_lookup/`进入实验根目录运行：

```bash
cd ..
python3 tests/run_checks.py
```

脚本会生成`test-results/run-日期时间/`，每次目录不同，保留随机种子、原始输出与CSV/JSON。截图2取前三组PASS输出，证明两版分别通过独立线性最长前缀基准；异常检测由Sanitizer启用，有错误时脚本会失败，而不是继续给出成功结果。

截图3取5轮原入口输出，或者在同一个WSL终端显示真实生成的CSV：

```bash
cat test-results/你的本次目录/performance.csv
```

截图4显示同一目录的真实内存统计：

```bash
cat test-results/你的本次目录/memory.txt
```

将“你的本次目录”替换为脚本末尾打印的目录名。不是重新生成终端图，仅查看实际运行日志。若用自己新测的截图，报告的5轮耗时、中位数、加速比及结论也要按新CSV更新；内存计数在相同数据与结构上应保持不变。

报告参考结果保存在`test-results/run-20261106-085148/`。其中基本树分配39518040字节；优化表使用59246592字节，但实际分配67108864字节。报告按后者计算空间开销，不要把使用量与分配容量混为一谈。
